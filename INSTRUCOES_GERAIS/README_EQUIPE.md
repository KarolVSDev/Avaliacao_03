# Ambiente Simulado — Avaliação Prática 03

Este pacote contém os **dados e sistemas simulados de entrada/apoio**. Não inclui solução, código do robô ou gabarito.

- Cada equipe recebe somente sua pasta.
- Dados e credenciais são fictícios.
- O robô deve ler caminhos/URLs/credenciais por `.env`.
- Fuso exigido: `TZ=America/Manaus`.
- Para servir as páginas fake: `python -m http.server 8000` dentro da pasta da equipe.
- Credenciais web de teste: usuário `aluno`, senha `avaliacao2026`.
